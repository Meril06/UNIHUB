## 📖 About

**UNIHUB** is a centralized academic support platform designed to help university students thrive. Whether you need study materials, peer collaboration, assignment tracking, or access to campus resources, UNIHUB brings everything together in a single, easy-to-use hub.

> Empowering students to achieve more — together.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📚 **Resource Library** | Access lecture notes, past papers, and study guides shared by peers and faculty |
| 🤝 **Peer Collaboration** | Find study partners, form groups, and collaborate on projects |
| 📅 **Assignment Tracker** | Keep track of deadlines, submissions, and course milestones |
| 💬 **Discussion Forums** | Ask questions, share knowledge, and get help from your academic community |
| 🔔 **Smart Notifications** | Stay on top of upcoming deadlines and campus announcements |
| 🏛️ **Campus Directory** | Quickly find departments, faculty contacts, and support services |
| 📊 **Progress Dashboard** | Visualize your academic progress and set personal goals |

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+  
- [Git](https://git-scm.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Meril06/UNIHUB.git

# 2. Navigate into the project directory
cd UNIHUB

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. 🎉

## 🛠️ Tech Stack

- **Frontend:** React / Next.js
- **Backend:** Node.js / Express
- **Database:** MongoDB
- **Authentication:** JWT / OAuth
- **Styling:** Tailwind CSS
